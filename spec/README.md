# FlowHub Spec Folder

This folder contains the implementation rules, ways of working, and prompt guidance for Claude when working on FlowHub.

Files:
- `claude-ways-of-working.md` — mandatory TDD and stepwise workflow rules.
- `claude-prompt-template.md` — recommended system prompt template for feature implementation requests.

How to use:
1. Open `spec/claude-ways-of-working.md` and review the mandatory rules.
2. When asking Claude to implement a feature, refer to this folder explicitly.
3. Use the prompt template in `spec/claude-prompt-template.md` as a starting point.
